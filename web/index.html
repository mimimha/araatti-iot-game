바닷속에서 함께하는 협동 미니게임

구글 드라이브에서 받기 Windows · 약 375MB 이 서버에서 바로 받기 Windows · 약 375MB

어느 쪽으로 받아도 게임은 같습니다. 아라아띠는 서버 한 대에서 게임 서버 7대와 이 사이트를 함께 운영합니다. 드라이브에서 받으시면 그만큼의 회선이 게임 쪽에 남아, 지금 접속해 있는 분들이 더 쾌적하게 플레이할 수 있습니다.

실행 방법

  1. 받은 AraAtti-EC2.zip 의 압축을 풉니다. ⚠ 드라이브에서 받으실 때 "바이러스 검사를 할 수 없습니다" 가 뜨면 무시하고 다운로드 를 누르세요. 파일이 커서 구글이 검사하지 못할 뿐입니다.
  2. 폴더 안의 게임시작.bat 을 더블클릭합니다. ⚠ AraAtti-Flow.exe 를 직접 실행하면 서버에 연결되지 않습니다.
  3. 파란 경고창이 뜨면 추가 정보 → 실행 을 누릅니다. ⚠ 서명되지 않은 프로그램이라 Windows 가 한 번 묻습니다.
  4. 게임이 열리면 회원가입 부터 합니다. ⚠ 처음이라 계정이 없습니다. 로그인이 아니라 회원가입입니다.

이렇게 즐깁니다

캐릭터를 만들고 로비에 모입니다. 포탈에서 광산 · 검 · 배 세 가지 미니게임 중 하나를 고르고, 몇 명이서 할지 정하면 같은 인원을 고른 사람들과 묶여 게임이 시작됩니다. 끝나면 다시 로비로 돌아옵니다.

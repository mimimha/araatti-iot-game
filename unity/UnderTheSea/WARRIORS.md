# 무쌍 게임 (Warriors) 규격

담당: 서연 · 씬: `Assets/Game/Scenes/Main/MiniGames/Warriors.unity`

본 문서는 무쌍 미니게임의 규칙과 구현 규격을 정의합니다.

`GAME_STRUCTURE.md` 8장의 미니게임 공통 규격(4명 고정 / 결과는 성공여부 + 점수)을 전제로 합니다.

> **이 문서는 구현 진행 상황을 함께 담고 있습니다.**
> 아직 확정되지 않았거나 IoT 연동을 기다리는 항목은 9장에 모아두었습니다.

---

## 1. 한 줄 요약

해변으로 몰려오는 바다 몬스터를 **종류에 맞는 공격**으로 베어 넘기고,
마지막에 크라켄을 쓰러뜨리는 3라운드 전투 게임입니다.

---

## 2. 공격 3종과 몬스터 대응

플레이어의 공격은 3가지뿐입니다. 몬스터마다 통하는 공격이 하나로 정해져 있습니다.

| 몬스터 | 통하는 공격 | 기호 | 키보드(검증용) |
| --- | --- | --- | --- |
| 물고기 | 가로베기 | ↔ | `1` |
| 게 | 세로베기 | ↕ | `2` |
| 해파리 | 찌르기 | ⊙ | `3` |

**틀린 공격은 데미지가 들어가지 않습니다.** 몬스터가 잠깐 튕겨내는 반응만 합니다.

> ⚠ 키보드 `1` `2` `3` 은 **IoT 장치 없이 검증하기 위한 임시 입력**입니다.
> 실제 입력은 IoT 검을 휘두르는 방향으로 들어옵니다. (`WarriorsIoTInput.OnSwing`)
> `W` `A` `S` `D` 는 플레이어 이동이므로 공격에 쓰지 않습니다.

---

## 3. 라운드 구성

### ROUND 1 · 해변 방어

해변으로 몬스터가 몰려옵니다. **목표 처치 수를 채우면** 다음 라운드로 넘어갑니다.

| 항목 | 값 |
| --- | --- |
| 목표 처치 수 | **30** (`WarriorsGameRoot.prefab` → `BattleScore.targetKills`) |
| 제한 시간 | 180초 |
| 등장 몬스터 | 물고기 / 게 / 해파리 |
| 실패 조건 | 시간 초과 |

몬스터는 스폰 후 플레이어에게 접근해 사거리(2.2m)에서 멈추고 공격합니다.
**플레이어에게서 물러나지 않습니다.** 서로 겹치지 않게 옆으로만 비껴갑니다.

> 개발 검증용 씬(`Scenes/Develop/SeoYeon/WarriorsTest.unity`)에서는
> 한 판이 빨리 끝나도록 목표 처치 수만 **10** 으로 낮춰 두었습니다.
> 메인 씬의 값(30)은 건드리지 않습니다.

### ROUND 2 · 촉수 절단

크라켄이 촉수 4개를 내밉니다. 각 촉수에 **어떤 공격이 통하는지 기호가 붙어 있고**,
그 기호와 같은 공격으로 베어야 잘립니다.

| 항목 | 값 |
| --- | --- |
| 촉수 수 | 4 |
| 진행 조건 | 4개 모두 절단 |

### ROUND 3 · 최후의 일격

크라켄 본체와의 리듬 전투입니다. 공격 아이콘이 위에서 내려오고,
**판정선에 닿는 순간 해당 공격**을 입력합니다.

| 항목 | 값 |
| --- | --- |
| 진행 조건 | 노트를 모두 처리 |
| 표시 | 크라켄 체력 / 노트 레인 / 판정 |

판정은 `완벽!` · `좋아요!` · `놓쳤어요` 세 단계입니다.

## 4. HUD 규격

1920x1080 기준. 짙은 남색 둥근 카드에 청록/노랑 accent, 흰색 텍스트로 통일합니다.

```text
┌ ROUND / TIME ┐        ┌ 라운드 진행도 ┐        ┌ HP / SCORE / COMBO ┐
└ 목표 한 줄 ──┘        └──────────────┘        └────────────────────┘
                                                 ┌ 1P~4P READY/WAIT ┐
                                                 └──────────────────┘

                      (전투 공간 - UI가 가리지 않는다)

                    ┌ 라운드별 공격 안내 3장 ┐
                    └───────────────────────┘
```

| 위치 | 내용 |
| --- | --- |
| 상단 좌 | ROUND 이름 · TIME · 이번 라운드 목표 한 줄 |
| 상단 중앙 | ROUND 1 처치 수 / ROUND 2 잘라낸 촉수 / ROUND 3 크라켄 체력 |
| 상단 우 | HP · SCORE · COMBO (한 카드) + 플레이어 4칸 상태 |
| 하단 중앙 | ROUND 1 몬스터 카드 3장 / ROUND 2·3 공격 카드 3장 |

### 라운드 시작 안내

라운드가 바뀌면 화면 중앙에 2줄 안내가 **3초** 뜹니다.
이 동안 스폰·타이머·리듬 노트가 모두 멈춥니다. (`Time.timeScale = 0`)

안내가 닫히면 두 번째 줄만 **좌상단 TIME 카드 아래 한 줄**로 남습니다.

| 라운드 | 상황 | 지시 |
| --- | --- | --- |
| 1 | 해변으로 몬스터들이 몰려오고 있습니다! | 몬스터 종류에 맞는 공격으로 처치하세요! |
| 2 | 크라켄이 섬을 공격하기 시작했습니다! | 촉수의 표시와 같은 공격을 사용하세요! |
| 3 | 크라켄이 마지막 공격을 준비합니다! | 내려오는 공격 아이콘을 타이밍에 맞춰 공격하세요! |

### 피드백 원칙

**화면에 글자를 더 띄우지 않습니다.** 기존 UI가 반응하게 합니다.

- 공격하면 → 해당 하단 카드가 커지고 밝아졌다가 돌아옵니다
- 틀린 공격 → 몬스터가 튕겨내는 반응만, 안내 문구 없음
- 피격 → 화면 가장자리에 짧은 붉은 기색

## 5. 프리팹 구성

전투 콘텐츠는 전부 프리팹에 들어 있습니다. 메인 씬은 이 프리팹들을 배치만 합니다.

```text
Assets/Game/Prefabs/MiniGames/Warriors/
├── Core/WarriorsGameRoot.prefab       진행·점수·스폰·입력 라우터
├── Arena/WarriorsBeachArena.prefab    해변 무대와 스폰 지점
├── UI/WarriorsHUD.prefab              HUD 전체
├── Boss/WarriorsKrakenBoss.prefab     크라켄과 촉수
├── Enemies/CrabEnemy.prefab
├── Enemies/FishEnemy.prefab
├── Enemies/JellyfishEnemy.prefab
└── Player/WarriorsStandalonePlayer.prefab
```

플레이어는 씬에 미리 두지 않고 `WarriorsSceneBootstrap` 이 **런타임에 생성**합니다.

## 6. 결과 화면

| 상태 | 표시 |
| --- | --- |
| 성공 | 승리! · 최종 점수 / 플레이 시간 / 몬스터 처치 |

## 7. 4인 플레이

미니게임 인원은 4명 고정입니다.

| 항목 | 현재 상태 |
| --- | --- |
| 플레이어 4칸 표시 | 실제 접속 인원만 READY, 나머지 WAIT |
| 공격 입력 | `WarriorsIoTInput.OnSwing(playerId, ...)` 로 0~3번 플레이어 구분 |
| ROUND 3 노트 레인 | 접속 인원 수만큼 열림 (1인이면 가운데 한 줄) |

## 9. 확정이 필요한 항목

작업을 이어가기 전에 정해야 하는 것들입니다.

| 항목 | 현재 | 메모 |
| --- | --- | --- |
| 플레이어 무적 | **켜져 있음** (`WarriorsStandalonePlayer.prefab` → `immortalForTesting`) | 이 상태에서는 사망 종료가 발생하지 않습니다. ROUND 1 실패는 시간 초과뿐입니다 |
| ROUND 3 협동 마무리 | 코드에는 있으나 도달하지 않음 | 리듬 전투가 먼저 끝나 클리어로 넘어갑니다. 4인 IoT 입력이 붙은 뒤 다시 봅니다 |
| ROUND 3 노트 레인 판정 | 레인 구분 없이 가장 가까운 노트를 처리 | 4인일 때 남의 노트를 대신 칠 수 있습니다 |
| 크라켄 약점(`WeakPoint`) 머티리얼 | 비어 있음 | ROUND 3에서 기본 머티리얼로 보입니다 |
| `WarriorsBeachArena` 의 빈 Animator 2개 | 참조 없음 | 삭제된 테스트용 컨트롤러 자리입니다 |
| 점수 배분 | 일반 100 / 보스 250 | 밸런스 미확정 |

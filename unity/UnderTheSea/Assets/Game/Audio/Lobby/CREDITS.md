# 로비 소리 — 출처

## 헤엄 · 잠수 효과음 (전부 CC0)

원본 팩: [40 CC0 water / splash / slime SFX](https://opengameart.org/content/40-cc0-water-splash-slime-sfx) (opengameart.org). 받은 날: 2026-09-25.
배 협동의 dumpSplash · waterScoop 과 같은 팩이다.

| 파일 | 원본 | 쓰는 곳 |
| --- | --- | --- |
| swimStroke1 · swimStroke2 | splash_02 · splash_13 | 헤엄치며 팔을 저을 때 (돌아가며) |
| diveIn | splash_01 | 머리가 물에 잠기는 순간 |
| surfaceOut | splash_05 | 잠겼던 머리가 물 밖으로 나오는 순간 |
| underwaterLoop | loop_bubbles_02 | 잠겨 있는 동안 깔리는 물방울 루프 |

`LobbySwimAudio` 가 낸다. 메뉴 `Tools/아라아띠/로비 물속 연출 프리팹 만들기` 를 돌리면 파일 이름대로 연결된다 (AUDIO.md 5장).
다른 소리로 바꿀 때는 같은 이름으로 덮어쓰고 메뉴를 다시 돌린다. 젓는 소리는 `swimStroke` 로 시작하면 몇 개든 들어간다.

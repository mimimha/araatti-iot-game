# 아라아띠 Unity Client

작업을 시작하기 전에 반드시 아래 문서를 읽고 해당 규칙을 준수한다.

- `../../GIT_CONVENTION.md` — 브랜치 이름, 커밋 메시지, Merge Request 규칙
- `CONVENTION.md` — Unity 파일과 폴더를 어디에 두는가
- `GAME_STRUCTURE.md` — 각자 만든 것을 어떻게 이어붙이는가 (씬 흐름, 네트워크, 담당별 규격)
- `IOT_INPUT.md` — IoT 장치가 구현할 입력 규격과 게임별 키를 그렇게 정한 이유
- `Assets/Game/Scripts/IoT/KEY_MAPPING.md` — 게임별 완드 ↔ 키보드 대응표 (정본)
- `Assets/Game/Scripts/IoT/IotPlayerController.md` — 완드 작업의 **진행 상황과 인계**. IoT 를 건드리기 전에 **7-7 을 먼저 읽는다** (게임별로 어디까지 닿았는지 · 남은 일 · 이미 조사해 둔 것). 세션이 여러 개로 갈려 있어 여기가 유일한 정본이다
- `AUDIO.md` — 배경음악 · 효과음을 어느 씬 · 미니게임에든 넣는 법 (공용 AudioHub)
- `ASSETS.md` — 사용한 외부 에셋 기록

# 아라아띠 시연 시나리오

C101 팀 · 총 **7분 19초** · 참가자 **P1~P4 (4명)**

원본: `C101_아라아띠_시연 시나리오.docx`. 구간 · 시간 · 멘트는 원본 그대로이고, **조작** 칸(누르는 키 · 클릭 위치)을 덧붙였습니다.
키보드 기준이고, 괄호 안은 IoT 완드(왼손 L · 오른손 R) 입력입니다.

## 0. 시연 전 준비

| 항목 | 내용 |
|---|---|
| 클라이언트 | https://araatti.site 에서 zip 을 받아 풀고 **`게임시작.bat`** 으로 실행 (exe 를 직접 실행하면 서버 주소가 안 들어가 로그인이 안 된다) |
| 완드 | 수신 동글을 **게임을 켜기 전에** USB 에 꽂는다. 처음 한 번 드라이버 설치 확인 창 → [예] |
| 서버 | EC2 게임 서버 7대 · API 가 떠 있는지 확인 (01_포팅매뉴얼 6장) |
| 계정 | P1 은 시연 중 새로 만든다. P2~P4 는 미리 로그인해 로비에서 기다린다 |
| 섬 회복도 | 제단 연출이 보이도록 100% 아래로 맞춰 둔다 (개발자 패널 `P` → `;` · `[`) |
| 화면 | 전체화면으로 켜진다. 창으로 바꾸려면 `Alt+Enter` |

## 부록 — 시연을 빨리 넘기는 개발자 패널

클라이언트와 서버가 `-devmode` 로 떠 있어서 쓸 수 있습니다. 어디서든 **`P`** 로 열고 닫습니다.

| 어디 | 키 | 하는 일 |
|---|---|---|
| 로비 | `]` · `[` / `'` · `;` | 섬 회복도 +1 · -1 / +10 · -10 |
| 로비 | `\` | 제단 봉헌 연출 미리보기 (내 화면만) |
| 로비 | `/` | 제단 완성 영상 미리보기 (내 화면만) |
| 광산 | `]` · `-` | 지금 턴 건너뛰기 · 무조건 성공으로 끝내기 |
| 배 협동 · 무쌍 | 패널 안내 참고 | 페이즈 넘기기 등 |

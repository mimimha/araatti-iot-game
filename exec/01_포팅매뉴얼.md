## 1. 전체 구성

```
플레이어 PC (Windows)                     AWS EC2 t3.xlarge · Ubuntu 24.04 (43.202.67.137)
 Unity 클라이언트 ── UDP 27015~27021 ──▶  게임 서버 7대 (Photon Fusion Dedicated Server, 리눅스)
       │                                    로비 1 · 광산 2 · 검(무쌍) 2 · 배 협동 2
       ├──────── HTTP 5080 ────────────▶  계정 API (ASP.NET Core 8, Kestrel) ── MySQL 8.4 (Docker, 127.0.0.1 만)
       └──────── HTTPS 443 ────────────▶  nginx — 홈페이지 araatti.site · 게임 다운로드 zip
```

이 프로젝트는 Java 가 아니라 **Unity(C#) 게임 + .NET API** 구성이라 JVM · WAS 가 없습니다.

## 4. 빌드

### 4-1. 게임 — 게임 서버 4종 + 클라이언트 (Windows, PowerShell)

```powershell
# Unity 를 닫은 상태에서. 리눅스 서버 4종 → 윈도우 Release 클라이언트 순서로 굽는다 (약 5분)
powershell -ExecutionPolicy Bypass -File tools\deploy\build-release.ps1

# 클라이언트 + 실행 배치(게임시작.bat) + 안내문 + 완드 드라이버 → zip
powershell -ExecutionPolicy Bypass -File tools\deploy\pack-client.ps1
```

| 결과물 | 위치 |
|---|---|
| 게임 서버 4종 | `unity/UnderTheSea/Builds/Linux/{Server, MineServer, WarriorsServer, ShipCoopServer}` |
| 클라이언트 | `unity/UnderTheSea/Builds/Showcase/AraAtti-Flow.exe` |
| 배포 zip | `unity/UnderTheSea/Builds/AraAtti-EC2.zip` (약 460MB) |

- `build-release.ps1` 은 Unity 를 배치 모드로 **순서대로** 띄웁니다(한 프로젝트를 두 Unity 가 동시에 못 연다). 에디터가 열려 있으면 실패합니다.
- Unity 경로는 `C:\Program Files\Unity\Hub\Editor\6000.5.9f1\Editor\Unity.exe` 로 적혀 있습니다. 다르면 스크립트 첫 줄을 고칩니다.

### 4-2. 계정 API

```bash
dotnet publish server/AraAtti.Api/AraAtti.Api.csproj -c Release -r linux-x64 --self-contained false -o <폴더>
tar -czf api.tar.gz -C <폴더> .
```

⚠ `--self-contained false` 여야 합니다. SDK 10 으로 net8.0 을 self-contained 로 굽으면 프레임워크 DLL 이 빠진 채 나와 EC2 에서 켜지지 않습니다. EC2 에는 `aspnetcore-runtime-8.0` 이 깔려 있습니다.

### 4-3. 홈페이지

```bash
cd web
npm install
npm run build          # dist/ 생성
```

### 4-4. 로컬에서 개발 · 실행 (선택)

```bash
cd server
cp .env.example .env                 # MYSQL_ROOT_PASSWORD · MYSQL_PASSWORD 를 채운다
docker compose up -d                 # araatti-mysql (127.0.0.1:3306)
cp AraAtti.Api/appsettings.Development.json.example AraAtti.Api/appsettings.Development.json   # 접속 문자열 · JWT 키
dotnet tool restore                  # 마이그레이션 도구(dotnet-ef) — 버전은 .config/dotnet-tools.json 에 고정
dotnet ef database update --project AraAtti.Api
dotnet run --project AraAtti.Api     # http://localhost:5080, Swagger /swagger
```

자세한 순서는 `server/README.md` 에 있습니다. Unity 에디터에서 Play 하면 클라이언트는 기본적으로 `http://localhost:5080` 의 API 를 씁니다.

## 6. EC2 배포

### 6-1. 순서

```bash
# ① 접속자 확인 — 3초 동안 게임 포트 패킷을 센다. 빈 서버는 1 줄이다. 그보다 많으면 배포하지 않는다
ssh -i J15C101T.pem ubuntu@43.202.67.137 \
  "sudo timeout 3 tcpdump -ni any -q 'udp and portrange 27015-27021 and not src host 43.202.67.137' | wc -l"

# ② 올리기
cd unity/UnderTheSea/Builds/Linux
tar -czf servers.tar.gz --exclude="*_BurstDebugInformation_DoNotShip" Server MineServer WarriorsServer ShipCoopServer
scp -i J15C101T.pem servers.tar.gz api.tar.gz ubuntu@43.202.67.137:~/araatti/staging/
scp -i J15C101T.pem ../AraAtti-EC2.zip ubuntu@43.202.67.137:~/araatti/staging/AraAtti.zip

# ③ 교체 — 멈추기 · 옛 빌드 백업 · 풀기 · API 교체 · 7대 다시 띄우기 · 포트 확인
ssh -i J15C101T.pem ubuntu@43.202.67.137 'cd ~/araatti && ./deploy-servers.sh'
ssh -i J15C101T.pem ubuntu@43.202.67.137 \
  'sudo mv ~/araatti/staging/AraAtti.zip /var/www/araatti/AraAtti.zip && sudo chown www-data:www-data /var/www/araatti/AraAtti.zip'

# ④ 홈페이지 (바뀌었을 때만)
cd web && npm run deploy          # 먼저 npm run deploy:dry 로 확인. AraAtti.zip 은 건드리지 않는다
```

## 7. 배포 시 특이사항

- **서버와 클라이언트는 한 벌로 올린다.** 네트워크 코드가 다른 빌드끼리는 `Behaviour count mismatch` 로 접속이 깨진다. 클라이언트 전용 변경(화면 · 영상)만 zip 만 올려도 된다.
- **접속자가 있을 때 배포하지 않는다.** `deploy-servers.sh` 는 게임 서버 7대를 모두 재시작한다(API 만 바꿔도 그렇다).
- **`-publicip` 이 없으면 아무도 못 붙는다.** 포트도 열려 있고 로그도 멀쩡해서 원인을 찾기 어렵다.
- **`.bat` 은 CRLF + CP949, `.ps1` 은 UTF-8 BOM** 으로 쓴다. 아니면 cmd 가 `set` 을 못 읽거나 PowerShell 5.1 이 한글을 깨뜨린다. `pack-client.ps1` 이 알아서 맞춘다.
- **`appsettings.Development.json` 은 배포본에 넣지 않는다.** 개인 DB 비밀번호 · JWT 키가 들어 있다. `.csproj` 의 `CopyToPublishDirectory="Never"` 와 `deploy-servers.sh` 가 이중으로 막는다.
- **systemd 등록이 없다.** `nohup` 으로 띄우므로 EC2 가 재부팅되면 `deploy-servers.sh` 를 다시 실행해야 한다.
- **완드 드라이버**: 배포 zip 의 `WandDriver\` 에 CP210x 드라이버가 있다. `게임시작.bat` 이 동글이 꽂혀 있고 드라이버가 없을 때만 관리자 확인 창을 한 번 띄워 설치한다(키보드만 쓰는 PC 는 묻지 않는다).
  ⚠ 드라이버 파일은 한 바이트도 바꾸면 안 된다(서명 `silabser.cat` 이 `silabser.inf` 의 해시). `.gitattributes` 에서 `tools/deploy/drivers/** -text` 로 줄바꿈 변환을 막았다.
- **SSAFY EC2 주의**: `shutdown` · `poweroff` 금지(다시 켤 수 없음), SSH 포트 차단 · 공개키 삭제 · `/home` 권한 변경 금지(복구 불가, 초기화만 가능). MySQL 컨테이너 · 볼륨은 지우지 않는다.

### 덤프로 복원했을 때의 시연 계정

[03_araatti_dump.sql](03_araatti_dump.sql) 은 개인정보를 가렸습니다. 복원하면 모든 계정이

## 1. Photon Cloud — Photon Fusion 2

| 항목 | 내용 |
|---|---|
| 가입 | https://dashboard.photonengine.com 에서 계정 생성 → **Create a New App** → Photon SDK: **Fusion**, 버전 **Fusion 2** |
| 받는 값 | **App ID (Fusion)** |
| 넣는 곳 | `unity/UnderTheSea/Assets/Photon/Fusion/Resources/PhotonAppSettings.asset` 의 `AppIdFusion` (Unity 메뉴 `Tools > Fusion > Realtime Settings` 에서도 입력 가능) |
| 지역 | **kr (한국)** 고정 — 게임 서버 `-region kr`, 클라이언트 `-region kr` |
| 세션 나누기 | AppVersion **prod** (`-appver prod`). 같은 App ID 를 써도 값이 다르면 서로 안 보인다 |
| SDK | Photon Fusion 2.1.2 Stable (저장소 `unity/UnderTheSea/Assets/Photon/Fusion` 에 포함) |

**방식 — Dedicated Server.** EC2 의 게임 서버 7대가 각자 Photon Cloud 에 세션을 등록하고(`-publicip` 필수),
클라이언트는 Photon 에서 세션을 찾아 그 게임 서버에 UDP 로 접속합니다. 로비 서버는 Photon 세션 목록만 보고 빈 미니게임 서버를 골라 매칭합니다(서버끼리는 통신하지 않음).

⚠ 무료 요금제는 동시 접속(CCU) 제한이 있습니다. 대시보드에서 앱별 한도를 확인합니다.

## 2. Google Gemini API — 광산 한 줄 평

| 항목 | 내용 |
|---|---|
| 가입 | https://aistudio.google.com → **Get API key** → 키 생성 |
| 넣는 곳 | EC2 `~/araatti/api.env` 의 `MineReview__ApiKey` (로컬은 `appsettings.Development.json` 의 `MineReview:ApiKey`) |
| 모델 | `gemini-3.5-flash-lite` (그림 입력을 받는 모델이어야 함) |
| 주소 | OpenAI 호환 엔드포인트 `https://generativelanguage.googleapis.com/v1beta/openai` + `/chat/completions` |
| 부르는 쪽 | 광산 게임 서버 → 같은 EC2 의 API(`/api/mine/review`, 같은 머신 요청만 허용) → Gemini |
| 제한 시간 | 5초. 넘기거나 키가 없으면 고정 문구 |

⚠ `gemini-2.5-flash` 는 목록에는 보여도 새 프로젝트에서 404 가 났습니다(2026-09 실측).

## 5. Silicon Labs CP210x 드라이버 — IoT 완드

| 항목 | 내용 |
|---|---|
| 필요한 이유 | 완드 수신 동글이 CP2102 USB-시리얼 칩(`VID_10C4&PID_EA60`)을 쓴다. 드라이버가 있어야 COM 포트로 잡힌다 |
| 버전 | CP210x Universal Windows Driver 11.6.0.420 (Microsoft 서명) |
| 받는 곳 | https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers |
| 저장소 | `tools/deploy/drivers/CP210x/` → 배포 zip 의 `WandDriver\CP210x\` |
| 설치 | `게임시작.bat` 이 동글이 꽂혀 있고 드라이버가 없을 때만 `pnputil /add-driver silabser.inf /install` (관리자 확인 한 번) |
| 라이선스 | 제품과 함께 재배포 가능, **드라이버만 따로 배포하는 것은 금지**. `SLAB_License_Agreement_VCP_Windows.txt` 동봉 |

게임은 COM 포트를 자동으로 찾습니다(포트 번호가 바뀌어도 됨). 동글은 게임을 켜기 전에 꽂습니다.

# IoT 튜토리얼 인게임 캡처

Unity 편집기에서 캡처 전용 Dedicated Server에 접속하여 실제 로비의 Game View를 1920×1080으로 저장했습니다. 배경 합성이나 생성 이미지가 아닙니다.

1. `01-move.png` — 이동 / 왼손 스틱 움직이기
2. `02-jump.png` — 점프 / 오른손 A 버튼 누르기
3. `03-camera.png` — 둘러보기 / 오른손 스틱 움직이기
4. `04-finish.png` — 다양한 사람들을 만나, 바다의 심장 조각을 함께 모아보세요.

기존 LobbyTutorial 프리팹의 컨테이너와 이미지 영역 크기를 유지하고, 실행 중인 복사본에만 `icon-iot-*-fit-v2.png` 및 안내 문구를 적용했습니다. 각 단계는 캡처용으로 표시했으며 실제 IoT 입력 완료 판정을 검증한 것은 아닙니다.

캡처용 임시 스크립트와 서버는 정리했습니다. 프리팹 및 게임 코드는 그대로이며, IoT 장치 연결 시 튜토리얼을 전환하는 기능은 아직 적용하지 않았습니다.

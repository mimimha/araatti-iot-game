# 팀 매칭 화면 — 빈 UI 에셋

레퍼런스의 항구, 짙은 남색 패널, 로프/불가사리 장식, 금색 본인 슬롯을 참고한 16:9 화면입니다. 실제 캐릭터, 로고, 닉네임, 버튼 문구를 분리한 조립식 구성입니다. 빈 대기열에는 별도 실루엣과 동적 물음표/매칭 상태를 표시합니다.

## 파일

PNG 에셋 15개. 도형 에셋 12개는 SVG 원본도 제공합니다. `preview.png`는 1600 × 900 조합 화면 캡처로, 개별 에셋 수에 포함하지 않습니다.

## 사용자가 바꾸는 내용

슬롯 입장/퇴장 시 배경과 이름표의 light/dark sprite를 교체합니다. 본인 여부는 local-highlight만 켜고 끕니다. 닉네임, 매칭 중/완료 문구, 현재 인원, 안내 문구, 버튼 문구는 별도 TextMeshPro 텍스트입니다. 완료 시 spinner를 숨깁니다. 대기 중에는 RectTransform의 Z 회전으로 spinner를 움직입니다.

버튼에는 글자나 앵커 아이콘이 없습니다. 매칭 취소 이벤트, 서버 연결, 매칭 완료 후 씬 전환은 게임에서 구현해야 합니다. preview.html의 인원/상태 변경은 디자인 확인용이며 실제 매칭 동작이 아닙니다.

## 캐릭터 표시

캐릭터 에셋을 새로 만들지 않았습니다. 기존 인게임 캐릭터를 슬롯 중앙의 빈 영역에 배치합니다. UI 위에 캐릭터 모델을 표시하려면 별도 카메라 → 투명 배경 RenderTexture → RawImage 조합을 사용할 수 있습니다. 또는 카메라 앞에 실제 모델을 배치하는 기존 로비 구조에 연결합니다. 패널 이미지 뒤에 모델을 두면 남색 패널에 가려지므로 렌더링/레이어 순서를 확인하세요.

레이어 순서: 항구 배경(또는 실제 인게임 항구 씬) → 장식 패널 → 슬롯 배경 → 캐릭터 표시 → 슬롯 외곽선/본인 강조 → 이름표 → 동적 텍스트. 각 슬롯에서 캐릭터 표시 영역은 원본 좌상단 기준 대략 `(24,32)`부터 `(296,386)`까지입니다. 이름표는 `(16,390)`에 `288 × 76`으로 둡니다. 캐릭터 뷰에는 필요한 경우 별도 마스크를 적용합니다.

## 배치 / Unity

- preview는 16:9 기준입니다. 배경은 화면을 채우고 crop을 허용합니다.
- 메인 패널은 화면 좌측 8%, 상단 2.5%, 너비 84%, 원본 비율 1578:997 유지. 16:9 화면 높이의 약 94.5%를 차지합니다.
- 슬롯 행은 패널 좌우 여백 각 13%, 상단 26%. 4열, 열 간격은 행 너비의 4.4%, 각 슬롯 비율 2:3.
- 헤더는 패널 상단 12.5%, 부제 22%, 안내 74%, 버튼 79% 부근. 버튼 너비는 패널의 24%, 중앙 정렬.
- PNG UI: Sprite (2D and UI), Single, Alpha Is Transparency On, Pivot Center, Clamp, Bilinear, Mip Maps Off. 최초 확인 시 Compression None 권장.
- 장식 패널은 동일 비율 확대/축소로 사용하세요. 별도 9-slice 검증 없이 늘리면 로프/불가사리 장식이 왜곡됩니다.
- 슬롯 배경/프레임/강조는 고정 2:3 비율로 사용. 폭·높이를 조절할 때 Border L/R/T/B=48, Sliced로 모서리를 유지할 수 있습니다.
- 이름표는 L/R=24, T/B=0, Sliced, 높이 고정. 버튼은 L/R=40, T/B=0, Sliced, 높이 고정.
- spinner는 Simple, Preserve Aspect On. 실제 프레임 애니메이션/문구가 굽혀 있지 않습니다.

## 미리보기와 제작 방식

preview.html 기본 화면은 빈 대기열의 물음표와 매칭 중…만 표시하고 나머지 동적 문구는 비워둡니다. '예시 텍스트 표시'를 켜면 UI 레이어에만 예시 한국어 문구가 나타납니다. 현재 인원 0..4와 버튼 기본/눌림/비활성 상태를 조절할 수 있습니다.

배경과 장식 패널은 built-in image_gen으로 별도 생성했습니다. 생성 원본을 유지했고, 슬롯·버튼·spinner·divider는 코드 도형으로 제작했습니다. prompts.md에 최종 생성 프롬프트가 있습니다. build-assets.ps1 및 render-core.ps1로 도형 PNG/SVG를 재생성할 수 있습니다.

게임 프로젝트의 씬/프리팹에는 연결하지 않았습니다.

## v2 — 빈 대기열 표시

사용자 참고 이미지에 맞춰 slot-waiting-silhouette.png를 추가했습니다. imagegen으로 생성한 익명 해적 실루엣이며 실제 플레이어 캐릭터와 무관합니다. 카드 안에서 x=5%, y=3%, width=90%, height=80%로 비율 유지 배치합니다. preview에서는 밝기 65%로 표시합니다. 물음표는 별도 텍스트를 카드 중앙에, 매칭 중…은 어두운 이름표 위에 표시합니다.

플레이어가 입장하면 placeholder, 물음표, 대기 문구를 숨기고 기존 인게임 캐릭터/닉네임으로 교체합니다. 물음표와 문구는 PNG에 포함하지 않아 색상/언어를 바꿀 수 있습니다. 실루엣은 생성된 래스터 PNG만 제공하며 SVG 원본은 없습니다.

## v3 — 레퍼런스의 허리 위 구도로 교체

v2 전신 실루엣을 교체했습니다. 모자부터 허리까지의 실루엣만 사용합니다. 카드에서 x=11%, y=4%, width=78%, height=77%로 배치하며 하단은 이름표 뒤에 놓습니다. 이름표는 x=3%, width=94%, height=20%, bottom=3%입니다. 물음표는 글꼴에 따른 모양 차이를 없애기 위해 별도 slot-question-mark.png / .svg로 변경했습니다. x=34%, y=28%, width=32%, height=34%에 배치합니다. 인원 입장 시 두 이미지와 매칭 중… 문구를 함께 숨깁니다. v3 값이 앞선 v2 배치 설명보다 우선합니다.

## v4 — 세로 확장 패널

레퍼런스처럼 화면 세로 대부분을 덮도록 match-panel.png를 1578 × 997(약 1.58:1) 비율로 교체했습니다. 이전 넓은 패널은 match-panel-wide-backup.png로 보관했습니다. preview의 패널은 상단 2.5%, 너비 84%이며 16:9 화면에서 높이 약 94.5%입니다.

## v5 — 이름표 정렬 통일

입장 슬롯과 빈 대기 슬롯의 이름표 표시 크기를 동일하게 맞췄습니다. 모든 이름표는 슬롯 기준 `left=5%`, `width=90%`, `height=15.83%`, `bottom=3%`입니다. 텍스트 영역도 `left/right=7%`, `bottom=4%`, `height=14%`로 통일했습니다. PNG 두 파일은 원래부터 모두 288 × 76이며 실제 불투명 영역 높이도 73px로 동일합니다.

## v6 — 깨끗한 세로 확장 패널

마스크로 외곽을 잘라 만든 v4 패널을 폐기하고, 알파 경계와 네 모서리 장식이 온전한 v3 원본을 기반으로 다시 제작했습니다. 상단 250px과 하단 250px은 원본 픽셀을 그대로 유지하고, 장식이 없는 중앙 영역만 세로로 연장했습니다. 최종 `match-panel.png`는 1729 × 1093(약 1.582:1)이며 네 불가사리·로프·조개 장식이 잘리지 않고 외부가 투명합니다.

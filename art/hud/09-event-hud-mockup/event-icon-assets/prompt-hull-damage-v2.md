Use case: background-extraction / precise-object-redesign.
Asset type: production game HUD event icon sprite.
Input image 1: five-icon preview establishing the approved visual system. Input image 2: old hull-damage sprite to REPLACE, not preserve.
Create exactly ONE redesigned HULL DAMAGE AND FLOODING pictogram on a genuinely transparent RGBA square canvas.

- one simplified warm-ivory curved ship-hull side plate, broad horizontal silhouette, clearly part of a boat hull rather than a generic rectangle;
- one single large irregular dark navy breach hole near the center-lower area;
- exactly three short bold coral-red cracks radiating outward from that hole;
- one thick bright cyan stream of water visibly entering through the breach and curving inward/downward;
- no loose boards and no separate floating droplets.

Match the other approved event icons exactly: thick dark-navy outer edge, rounded chunky shapes, restrained polished 2.5D bevel, same lighting direction, same warm ivory/coral/cyan colors, same visual weight and padding. The breach hole must be the strongest focal point; the water stream must physically connect to it.

Output exactly one centered icon. No circular medallion, container, badge, text, label, tools, bandage shape, brick wall, window, full ship, ocean scene, detached shadow, watermark or canvas border. Generous even transparent padding and clean antialiased edges.

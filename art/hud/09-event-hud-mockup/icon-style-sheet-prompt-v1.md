# 이벤트 아이콘 스타일 시트 v1

제작: built-in image_gen. 기존 전체 HUD를 스타일 기준으로 사용하며, 이벤트 컨테이너에는 합성하지 않는 검토 단계.

Use case: stylized-concept.
Asset type: game HUD icon style exploration sheet, review-only.
Input image 1: STYLE REFERENCE. Analyze the actual icon language across the entire HUD, especially the warm-ivory heart, outlined clock, small sailboat and hand. Do not copy the gameplay scene or build an event HUD.

Create one clean 16:9 icon comparison board on a flat deep-navy background. The board must feel like a professional game UI style sheet, not concept art. Use a strict 2-row grid with seven equal columns.

Top row, labeled only by tiny neutral English captions underneath: HEART, CLOCK, SAILBOAT, HAND. Recreate these four reference pictograms faithfully as style anchors: warm ivory, broad simple shapes, restrained bevel/highlight, thin dark navy edge where needed, minimal depth, instantly legible at HUD size.

Bottom row: exactly three new event pictograms following the SAME visual grammar and visual weight:
- REEF: one asymmetrical three-peak rock silhouette in warm ivory, with one restrained cyan wave stroke at the base. It must read as hazardous rock, not iceberg or mountain landscape.
- ENEMY SHIP: compact side-view sailing ship silhouette in warm ivory, with one tiny coral triangular flag. No skull, no face, no cannon, no rope detail.
- HULL DAMAGE: two overlapping warm-ivory planks with one bold coral zigzag crack and exactly two small cyan droplets. It must read as damaged wooden hull, not bandages.

For every icon, show a large 160px design and directly below it a tiny 48px preview of the same design so readability can be judged. Consistent scale, stroke weight, lighting direction, palette and padding across all seven symbols.

Critical constraints: standalone pictograms only; NO circular medallions, NO containers, NO buttons, NO gold rings, NO decorative frames, NO emoji faces, NO glossy sticker borders, NO realistic miniature scenes, NO gradients beyond a very subtle ivory highlight, NO extra variants, NO Korean text, NO descriptions or annotations beyond the seven tiny English names. Flat front view, centered. This sheet is for approving the icon system before asset extraction.

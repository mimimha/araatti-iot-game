# 가도가도 — 투명 HUD 에셋

기준 시안: `../minigame-hud-heart-only-v6.png` (사용자가 지정한 exec-88e41790 이미지와 같은 시안).

## 구성: 게임용 PNG 19개

- `panels/`: 출항·단계, HP, 시간, 항해 진행도, 경고, 4인 프로필 바탕, 상호작용 진행도 — 7개.
- `crew/`: 초상화 4개, 색 테두리 4개, 공용 프로필 배경 1개 — 9개.
- `fills/`: HP 초록, 항해 파랑, 상호작용 크림색 채움 — 3개.
- `preview.png`: 전체 확인용 이미지. 체크무늬는 이 미리보기에만 있습니다.
- `manifest.json`: PNG 크기, 알파 검증 결과, 권장 임포트 설정.
- `source/prompts.json`: 패널별 실제 이미지 생성 프롬프트.

모든 게임용 PNG는 RGBA이며 완전 투명 픽셀을 검증했습니다. 바깥 여백은 투명, 패널 안의 남색 바탕은 유지했습니다. 작은 분리 잡티는 정리했습니다.

## 제작 범위

패널은 built-in image_gen으로 원본 시안을 참고해 개별 투명 이미지로 재생성했습니다. 픽셀을 그대로 잘라낸 결과가 아니며, 원본과 비율·금속 장식·광택에 차이가 있습니다. 원본 파일은 보존했습니다.

초상화와 색 프레임은 기존 `art/hud/01-crew` 에셋을 재사용했습니다. 초상화는 512×512로 정리했으며, 목업에 그려진 얼굴과 세부 묘사가 다릅니다. 게이지 채움은 기존 프로젝트 SVG 채움 형태를 기반으로 색상·크기를 맞춘 별도 부품입니다.

패널에 하트·시계·돛·경고·손·조타 아이콘과 빈 트랙이 포함되어 있습니다. 이 고정 요소는 패널과 합쳐진 상태이며 별도 아이콘 레이어가 아닙니다. 텍스트·수치·게이지 채움·초상화·색 테두리는 패널에 포함되지 않습니다.

## Unity 사용

1. `panels`, `crew`, `fills` 폴더만 원하는 Unity Assets 경로로 복사합니다. 미리보기·source 폴더는 런타임에 필요 없습니다.
2. Texture Type: Sprite (2D and UI), Sprite Mode: Single, Alpha Is Transparency: On, Generate Mip Maps: Off, Wrap Mode: Clamp, Filter: Bilinear, Compression: None, Max Size: 2048.
3. 패널은 Image Type: Simple, Preserve Aspect 사용을 권장합니다. 아이콘이 합쳐져 있으므로 임의의 9-slice로 늘리면 아이콘과 장식이 왜곡됩니다.
4. `출항`, `100 / 100`, `2:59`, `이 속도면 늦는다!`, 플레이어 이름은 TextMeshPro로 별도 배치합니다. 단계 패널은 긴 `플레이어 입장중...` 문구에도 사용할 수 있지만 최종 표시 폭에 맞춰 글자 크기를 조정하세요.
5. 게이지 이미지는 각 패널의 빈 트랙 안쪽에 맞춰 배치합니다. Image Type: Filled → Horizontal → Left로 설정하고 fillAmount를 0~1로 변경합니다. 이 방식에서는 감소 시 오른쪽 끝이 직선으로 잘립니다. 오른쪽 둥근 끝을 항상 유지하려면 별도 둥근 마스크/레이아웃 처리가 필요합니다.
6. 프로필은 `crew-panel` 위에 4개 슬롯을 배치합니다. 슬롯마다 backplate → portrait → color frame 순서로 겹칩니다. 역할/이름은 아래에 별도 텍스트로 배치합니다. 실제 게임의 RenderTexture 얼굴을 사용한다면 제공 초상화 대신 RawImage를 사용하면 됩니다.
7. 패널의 내장 아이콘을 다시 추가하지 마세요. 중복 표시됩니다.

현재 씬·프리팹·게임 코드는 변경하지 않았습니다. 실행 중인 게임에서의 배치 및 동작 검증은 아직 하지 않았습니다.

## 재패키징

`tools/package.cjs`는 Sharp를 사용하여 저장된 생성 원본의 투명 여백 정리, PNG 검증, 미리보기·manifest 생성을 수행합니다. 패널 생성 원본은 `source/`에 보존되어 있습니다. 배포 ZIP에서는 용량을 줄이기 위해 생성 원본 PNG와 도구를 제외했습니다.
